# Audit evidence

These files support the September 11–12, 2026 operating-decision audit. Production code and frozen results were not edited. The development task independently completed and committed Stage 5 during the audit; the stored-result check reads that result without generating devices.

Run probes from the repository root with Python 3.10 or newer and the repository on `PYTHONPATH`. For example:

```bash
PYTHONPATH=. python3 docs/thermotwin/operating_decision_audit_2026_09_12/rng_probe.py
PYTHONPATH=. python3 docs/thermotwin/operating_decision_audit_2026_09_12/provenance_probe.py
PYTHONPATH=. python3 docs/thermotwin/operating_decision_audit_2026_09_12/final_stored_result_probe.py
```

The provenance probe always mocks the final generator. The final stored-result probe only reads JSON and recomputes arithmetic. Neither consumes an evaluation seed. The independent physics, energy, and optimizer probes use nominal cases or previously used Stage 3 development devices. They print results to standard output; redirect to a new file to retain a fresh reproduction.

| Files | Purpose |
| --- | --- |
| `rng_probe.py`, `rng_results.txt` | Reproduce collisions across measurement runs and adjacent device blocks |
| `provenance_probe.py`, `provenance_results.txt` | Show that the source-revision label is not verified against executing code |
| `independent_physics_probe.py`, `independent_physics_results.json`, `corner_refinement.json` | Separately written thermal equations and fifth-order solver; final file additionally refines the fast corner |
| `energy_probe.py`, `energy_results.json` | Compare assigned nominal energy with simulated per-device terminal energy for 120 existing development policy/device combinations |
| `optimizer_probe.py`, `optimizer_results.jsonl` | Continue ten candidate fits for an additional 30 iterations |
| `final_stored_result_probe.py`, `final_stored_result_audit.txt` | Independent arithmetic audit of 900 saved Stage 5 outcomes and all summaries/bootstrap calculations |
| `baseline_reproduction.txt`, `stage2_reproduction.txt` | Full numerical reproductions run during this audit |
| `stage4_existing_report.txt`, `guard_calibration_existing_report.txt` | Previously generated aggregate reports inspected for consistency; not regenerated by this audit |
| `full_test_suite.log` | 602 passing tests, including optional scientific and figure tests |
| `minimal_runtime_tests.log` | Initial run without optional dependencies; superseded by the full-environment result |
| `source_manifest.json` | SHA-256 snapshot of tracked source, tests, documents, and result files at final audit revision |

The full suite used CPython 3.10.12 with the optional dependencies. The
standard-library probes and baseline reproductions used a bundled CPython
3.12.14 interpreter. Machine-specific executable paths are omitted here; the
raw historical logs retain them. No dependencies were installed during the
audit.

The source manifest also records pre-existing unrelated local report edits, because the test suite ran against the working tree. Numerical operating-decision source matched `f95538a`; later reviewed commits `93e401f` and `3a030de` added calibration/final artifacts and documentation.
